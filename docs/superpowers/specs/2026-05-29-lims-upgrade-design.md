## 需求1: UI全面重构

### 现状问题
HeyUI 1.25 组件样式陈旧，表格列过多，操作按钮分散，审核用Tooltip气泡框交互差。

### 方案
不换框架，通过自定义主题 + CSS重构 + 组件重新封装实现新界面风格。

### 实现细节

**主题层**:
- 新建 `src/theme/modern.less`，覆盖 HeyUI 默认变量（圆角、阴影、配色）
- 主色调从蓝灰改为现代青蓝色系
- 统一间距、字体大小、阴影层级

**布局层**:
- 列表页统一为"顶部筛选条 + 操作栏 + 表格"三段式
- 详情页统一为"顶部信息卡 + Tab内容区"
- 审核页改为分屏布局（见需求8）
- 每个列表页只显示核心字段（5-8列），其余通过展开行或查看详情显示

**组件封装**:
- 重新封装 `rs-template` 系列模板组件
- 精简冗余操作按钮
- 统一卡片、表格、表单样式

### 涉及文件
- 新建: `src/theme/modern.less`
- 修改: `src/components/rs-template/` 下所有模板组件
- 修改: `src/components/rs-table/`、`src/components/rs-form/` 样式
- 修改: `src/assets/style.css`、`src/assets/public.css`
- 修改: 各业务模块 `views/*.vue` 页面布局

## 需求6: 页面切换/证书预览速度优化

### 现状问题
- 证书预览每次调用后端 A49(printPreview) → Socket触发docx转pdf → 下载 → 渲染，链路长
- 页面切换时每个Tab都重新加载，无缓存

### 方案

**PDF缓存**:
- 后端生成PDF后缓存到磁盘，前端优先请求缓存版本
- `FileController.DownLoadPdf` 增加缓存检查：如果.pdf文件已存在直接返回，不再触发转换
- 新增 `GET /api/File/pdf/{id}?cache=1` 参数

**前端预加载**:
- 审核页面进入时（点击"开始审批"），批量预加载当前委托单下所有证书PDF
- 使用 IntersectionObserver 懒加载可视区域外的PDF

**PDF渲染优化**:
- 替换 `<rs-print-pdf>` 组件实现，改用 PDF.js canvas 渲染模式
- 支持按需加载页面（不一次加载整个PDF）
- 渲染完成后缓存canvas，切换记录时直接复用

**Tab缓存**:
- `<router-view>` 外包裹 `<keep-alive>` 缓存已打开的业务页面组件
- 需处理 keep-alive 下 store 数据刷新问题

### 涉及文件
- 修改: `src/components/printPdf/`（PDF渲染优化）
- 修改: `src/components/main.vue`（keep-alive）
- 修改: `netcore/Realso.WebAPI/Controllers/FileController.cs`（缓存检查）

## 需求9: 费用管理重构

### 现状
费用在受理单(m05)中通过 `PTEMPLATECAMT * CNT + OAMT` 计算，由前台手动关联。前台人员未必熟悉专业依据，无法精确确定设备使用哪个标准/项目去检测。

### 方案
费用自动关联到实验室受理人员选择模板时隶属的项目费用。

### 实现细节
- 新建 `TSS_PROJECT_FEE` 表（项目费用标准表）：
  ```
  ID | PROJECT_NAME | TEMPLATE_ID | CAMT(检测费) | OAMT(其他费) | BAMT(加急费) | VALID
  ```
- 受理单选择模板后，自动从 `TSS_PROJECT_FEE` 查询对应项目费用并填充
- 费用管理界面(r01/m03, r01/m031) 按委托单→项目的树形结构展示
- 增加"按项目汇总"视图，便于财务统计

### 涉及文件
- 修改: `src/pages/r01/m03/`、`src/pages/r01/m031/` 费用管理页面
- 修改: `src/pages/r01/m05/views/add.vue`（模板选择后自动填充项目费用）
- 后端: 新建项目费用标准表和对应API
- 数据库: 新建 `TSS_PROJECT_FEE` 表

- 在现有签发页(r01/m023)增加"电子签发"按钮
